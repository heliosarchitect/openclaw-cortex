### Critical Insights
1. **Bash-before-answer execution order**: LLMs hallucinate command output if allowed to generate `<bash>` + `<answer>` in one turn. Truncate after first `</bash>`, force execution. This single fix = +47.7% on AgentBench.
2. **SWE-bench patch capture via git diff, not model `<patch>` tag**: Model-copied diffs have whitespace corruption.
3. **Full clone required for SWE-bench**: Shallow clones miss target base commits.
4. **Background process `start` field**: AgentBench tasks use `create.init` + `start` in sequence; `docker exec -d` + 2s warmup.
5. **Prompt engineering dead end for τ²-bench**: Fixing Task 2 broke Task 8. Structural improvements needed.
