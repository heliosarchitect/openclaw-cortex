## 💡 Lessons Learned
1. **"Don't just manually kick it, FIX THE PROCESS"** — Matthew's #1 principle. Every manual intervention should trigger a structural fix.
2. **Plugin architectures > hardcoded lists**: Always design for extensibility. Radio, fleet, weather, drone — new domains should be a dropped file.
3. **Thread-per-task, not thread-per-agent**: The Synapse threading insight applies broadly — group by work unit, not by worker.
4. **Ship features first, test after**: Tests on moving targets waste effort. Tests on shipped features catch regressions.
5. **Emoji reactions are a real UX win**: 👍 instead of a 50-token reply. Matthew's instinct was right.
