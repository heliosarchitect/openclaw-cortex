# PR Title: Add WEMS - World Event Monitoring System

## Description

Adding **WEMS (World Event Monitoring System)** - a production-ready MCP server for real-time natural hazard monitoring.

### What is WEMS?
WEMS connects AI assistants to authoritative natural hazard data sources including:
- 🌊 **Earthquakes** (USGS)
- 🌊 **Tsunamis** (NOAA Pacific + Central Warning Centers)  
- 🌋 **Volcanoes** (Smithsonian GVP)
- ☀️ **Solar Events** (NOAA Space Weather)

### Key Differentiators
- **Freemium Model**: Free tier (earthquakes ≥4.5 magnitude, hour/day timeframes) + Premium tier ($29/mo) with full access
- **Zero Configuration**: Works out-of-the-box, configure only what you need
- **Production Ready**: Docker support, webhook alerts, comprehensive error handling
- **Authoritative Sources**: Direct integration with USGS, NOAA, and Smithsonian data feeds

### Technical Details
- **Language**: Python 🐍
- **Deployment**: Cloud-based data sources ☁️
- **Installation**: `pip install wems-mcp-server`
- **GitHub**: https://github.com/heliosarchitect/wems-mcp-server
- **PyPI**: https://pypi.org/project/wems-mcp-server/

### Use Cases
- Enterprise risk management for global operations
- News organizations for disaster reporting
- Personal safety and family location monitoring
- AI emergency response systems
- Custom alert and notification workflows
