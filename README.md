# openclaw-cortex

A practical, repo-first workspace for building and operating **Cortex** + **OpenClaw** automation in the LBF stack.

This repo currently contains a mix of:
- operational scripts and runbooks
- experiments / analysis artifacts
- reusable libraries and utilities

If you’re new here, start with:
- **Quickstart:** `docs/QUICKSTART.md`
- **Repo map:** `docs/REPO_MAP.md`

## Contributing

- Keep changes small and shippable.
- Prefer adding a doc + a testable script over large refactors.
- If you’re unsure where something belongs, add it and leave a note in the PR/issue — we’ll sort structure as we harden the repo.
